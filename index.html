Why this matters

Overflow isn't just a curiosity. It's a real source of bugs and vulnerabilities. A classic pattern:

if (len + 1 < buffer_size) { ... }: if len is at the maximum value, len + 1 wraps to a tiny number, the check passes, and a buffer gets overrun. Length and size calculations are where overflow does the most damage.

Two things to notice as you experiment: (1) adding past the maximum wraps around to the minimum instead of growing, because the value is always taken modulo 2width; (2) the exact same bit pattern is a large positive number when unsigned but can be negative when signed. For 8-bit, 0xFF is 255 unsigned but -1 signed.
